# QuizPlease SPB

Приложение для macOS: берёт PSD-макеты **бланков** и/или **дипломов** и сохраняет готовые **плоские RGB TIFF без сжатия** в одну папку.

Два независимых режима загрузки:

### Бланки
- `#квизплиз` → `#квизплизспб`
- `quizplease.ru` → `spb.quizplease.ru`
- QR-код → встроенный `QR_SPB.png` (картинку загружать не нужно)

### Дипломы
- перед каждым символом `#` в текстовых слоях добавляется `СПБ `;
- например, `Квиз, плиз! #` → `Квиз, плиз! СПБ #`;
- если `СПБ` уже стоит перед `#`, повторной замены не происходит.

В обоих режимах цветовая гамма **RGB** сохраняется как в исходнике.

```
/Users/annaleoncuk/Documents/githab/quizplease-spb/QuizPlease SPB.app
```

- Скопируйте бандл на другой Mac (например, в `/Applications`) и запустите двойным щелчком.
- У приложения своя иконка — логотип QuizPlease из присланного векторного файла.
- Откроется **нативное окно** — браузер не нужен. Приложение остаётся открытым, его не нужно перезапускать после каждой партии.

### Как пользоваться

1. **Папка результата.** По умолчанию `~/Documents/QuizPlease SPB`. Кнопка «Изменить…» открывает системный диалог выбора папки, «Открыть» показывает текущую папку в Finder.
2. **Макеты.** В окне две отдельные области: «Бланки» и «Дипломы». У каждой свой диалог «Добавить…» и своя область перетаскивания. В системном диалоге можно **одновременно** выбрать и отдельные `.psd`, и целые папки. Папки сканируются рекурсивно: все найденные в них PSD попадут в список. Можно загружать бланки и дипломы в одной партии — у каждого файла в списке есть пометка `БЛН` или `ДПЛ`.
3. **Обработка.** Нажмите «Создать TIFF». Файлы обрабатываются **строго по очереди**, один за другим: для бланков используется свой Photoshop-скрипт, для дипломов — свой. В списке видно состояние каждого макета: «В очереди» → «Обрабатывается…» → «Готово».
4. Готовые файлы сохраняются в выбранную папку как `<имя макета>_spb.tif`. Если файл с таким именем уже есть, добавляется суффикс `(2)`, `(3)` и т.д. — старые результаты не перезаписываются.
5. Можно сразу добавить новую партию и нажать «Создать TIFF» снова — окно приложения при этом не закрывается.

### Никаких подтверждений в Photoshop

- Скрипты запускаются через `open -j -a "Adobe Photoshop 2023" script.jsx` — **без Apple Events** и **без вывода Photoshop на передний план**.
- В ExtendScript выставлен `DialogModes.NO`, поэтому диалоги Photoshop подавлены.
- Разрешение «Allow JavaScript from Apple Events» включать не нужно — приложение его не использует.
- Во время работы можно продолжать пользоваться другими программами: Photoshop не перехватывает фокус.

Если Photoshop завис на системном диалоге, кнопка «Перезапустить Photoshop» внизу окна принудительно его перезапустит.

### Как передать приложение сотруднику

Нужно скопировать **только папку `QuizPlease SPB.app`** — внутри уже есть обе программы обработки, QR, логотип и интерфейс. Остальные файлы проекта (`server.rb`, `QR_SPB.png`, `README.md` и т.д.) передавать не обязательно.

На втором Mac:

1. Положите `.app` в `/Applications` (или в любую папку).
2. Уберите метку загрузки из интернета (иначе Gatekeeper может не пустить):
   ```bash
   xattr -dr com.apple.quarantine "/Applications/QuizPlease SPB.app"
   ```
   Либо первый раз откройте через контекстное меню → **Открыть**.
3. Запустите двойным щелчком. Папка результата `~/Documents/QuizPlease SPB` создастся сама.

Версию Photoshop приложение определяет само: поддерживаются `Adobe Photoshop 2023`, `2024`, `2025`, `2026`, а также старые имена вида `Adobe Photoshop CC ...`. Если Photoshop стоит в нестандартном месте и не находится, откройте:

```bash
nano "/Applications/QuizPlease SPB.app/Contents/Resources/server.rb"
```

найдите строку `PS_APP = detect_photoshop` и замените её на точное имя приложения, например:

```ruby
PS_APP = 'Adobe Photoshop 2024'
```

После правки переподпишите бандл:

```bash
codesign --force --deep -s - "/Applications/QuizPlease SPB.app"
```

Никаких дополнительных библиотек, Ruby, браузера или Xcode ставить не нужно — используется системный Ruby macOS.

### Gatekeeper на другом Mac

## Requirements

- macOS 10.15+
- Adobe Photoshop 2023 с поддержкой ExtendScript
- системный Ruby (`/usr/bin/ruby`) — входит в macOS

Сторонних библиотек, `ag-psd`, `psd-tools` и т.п. нет.

## Как находится QR

Поиск идёт по совокупности признаков, а не по имени слоя:

- смарт-объект;
- почти квадратный, 120–400 px;
- в нижней полосе макета рядом со слоями хештега и сайта;
- имя содержит подсказки `QR`, `клик`, `иконка`, `дважды`.

Поддерживаются оба известных варианта:

- `6 ответов.psd` — слой `YQR-4`;
- `лист для записи.psd` — слой `<-кликнуть дважды по иконке`.

Новый QR вставляется поверх старого по координатам слоя с масштабированием в его размер; старый смарт-объект удаляется. Это работает и там, где замена содержимого смарт-объекта через `placedLayerReplaceContents` проходит без реальной замены.

## Как добавляется СПБ в дипломы

Скрипт `render_diploma.jsx` обходит **все** текстовые слои, включая вложенные в группы, и ищет в содержимом символ `#`. Для каждого `#`:

- если перед ним уже стоит пробел — добавляется `СПБ ` перед `#`;
- если пробела нет — он добавляется автоматически;
- если `СПБ` уже есть перед `#`, слой не трогается.

QR-код в дипломах **не заменяется**. После правки документ сплющивается и сохраняется в TIFF с теми же параметрами: RGB, 300 dpi, без сжатия, без слоёв и альфы.

Проверено на примере `1-classic.psd`: слой `[HELLO 2027] #` стал `[HELLO 2027] СПБ #`.
